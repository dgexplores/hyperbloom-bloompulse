# BloomPulse — Project Description (HyperBloom Hacks, 298 words)

BloomPulse is an industrial sensor sentinel that predicts machine failure from a simple CSV upload and grounds every prediction in OSHA regulation. In US manufacturing, 70% of SMEs have no predictive maintenance; a single bearing failure causes 4–72 hours of downtime and $10k–$500k losses, plus OSHA 1910 fines up to $156k for lockout violations. Existing solutions like Siemens MindSphere cost $100k+/year and require IoT consultants, leaving 250k small factories to rely on manual vibration pens and paper manuals.

We built BloomPulse to close that gap with no hardware. A plant manager uploads a sensor CSV (timestamp, temperature, vibration, pressure, rpm) — the same data any PLC already logs. Our AI runs an Isolation Forest (150 trees) with LSTM-lite rolling features (vib mean, temp rise, pressure variance) on CPU in 60ms, outputting anomaly 0–1, 7-day failure probability, severity (normal/monitor/alert/critical), and root cause. If vibration exceeds 4.5 mm/s (ISO 10816-3 Zone D) or temperature rises >15C (NTN Manual Sec 4.2), the score is grounded to those thresholds rather than black-box.

Crucially, every alert is citation-grounded. An offline RAG assembler maps the anomaly to OSHA 29 CFR 1910.147 (lockout), ISO 10816-3, and manufacturer manuals, returning verbatim spans, locators, deep links, and a git-tracked corpus hash (bloompulse-2026.08.31-v1). Confidence 0–100 and a 0.70 abstain gate prevent hallucination; the UI shows an ELI5 explanation and one-click work order export (action, parts, downtime, lockout flag).

Built on FastAPI + React + scikit-learn, BloomPulse is 100% free to demo — no API key, no GPU, no wiring — using NASA CMAPSS-style synthetic data and public OSHA text. In 20 seconds, an uploaded anomaly CSV blooms into a critical alert with citations and a ready work order, saving downtime and fines. It is AI at the core, industrial at scale, and accessible to any factory with a laptop.
